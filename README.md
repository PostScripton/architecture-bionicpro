# architecture-bionicpro

Проектная работа 9 спринта курса «Архитектура программного обеспечения: продвинутый уровень» от Яндекс.Практикума.

Кейс: компания BionicPRO - производитель бионических протезов. После взлома SSO и утечки персональных данных пользователей нужно усилить безопасность системы, добавить пользователям отчёты о работе протезов и снизить нагрузку на базы данных.

Репозиторий изначально склонирован из шаблона курса и содержит рабочее приложение (Keycloak, LDAP, фронтенд) с изменениями из предыдущих уроков спринта - решения заданий дорабатывают это приложение.

- [how_to_complete_project.md](how_to_complete_project.md) - требования к сдаче работы
- [Task1](Task1) - Повышение безопасности системы
- [Task2](Task2) - Разработка сервиса отчётов
- [Task3](Task3) - Снижение нагрузки на базу данных

- [frontend](frontend), [keycloak](keycloak), [ldap](ldap), [docker-compose.yaml](docker-compose.yaml) - код приложения, унаследованный из предыдущих уроков спринта
